NOMAD ML Workflows¶

nomad-ml-workflows helps you turn NOMAD entries into reusable datasets and describe machine learning models alongside their artifacts, training metadata, and evaluations.

Choose an export action¶

Action Use it for Output
Export Entries Complete archives or selected archive paths from this deployment JSON, CSV, or a Parquet dataset in a staging project/upload
Export Forces Atomic structures with selected energies, forces, and stresses; shown as Export MLIP Data Action in the GUI Extended XYZ or an ASE database in a staging project/upload
Export Remote Entries Entries from configured Oases, optionally including this deployment One export per target in S3, optionally copied into a local staging project/upload

Each action runs independently. They share permission-scoped search and archive extraction, with Export Entries providing the foundation. Read the export explanation for selection, formats, manifests, and counts.

Start here¶

Follow the short Export Entries tutorial to save up to ten visible entries as JSON in a ZIP, using either the GUI or a Python REST client. Use the action chooser for task-specific guides.

Administrators can follow installation and configuration to enable the plugin, start a CPU worker, set limits, and configure remote targets and storage.

Describe a model¶

The ML model schema describes models independently of their implementation library and artifact format. Record model versions, libraries, files, training datasets, and evaluation metrics in a NOMAD entry. The related Dataset schema can describe data through NOMAD references, files, or URLs.
